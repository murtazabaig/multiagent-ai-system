# Multi-Agent AI System (Planner + Retriever + Executor)

## Overview
A modular multi-agent system for improved reasoning, retrieval, and execution in open-domain QA.

## Architecture
- Planner: Decomposes tasks
- Retriever: Fetches context
- Executor: Performs actions

## Setup
1. Install requirements: `pip install -r requirements.txt`
2. Run pipeline: `python -m src.core.pipeline`

## Project Structure
- src/: Source code
- data/: Datasets
- docs/: Literature and design docs
- configs/: Config files
- tests/: Tests
- notebooks/: Demos
