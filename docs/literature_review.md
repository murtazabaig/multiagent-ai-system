# Literature Review

## ReAct
- Combines reasoning and acting for better task decomposition and tool use.

## Retrieval-Augmented Generation (RAG)
- Integrates retrieval with generation for factual accuracy.

## AutoGPT
- Autonomous agent that decomposes goals and executes sub-tasks iteratively.

## Why Single-Agent Systems Are Insufficient
- Struggle with complex, multi-step reasoning and factual grounding.

## Why Planner + Retriever + Executor
- Modular, interpretable, and more robust for multi-step tasks.

## Limitations & Academic Framing
- Data and evaluation challenges, need for modularity, and error handling.
